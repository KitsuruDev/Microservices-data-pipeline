--------- 0. Собрать CdcHandler для mongodb в файл .jar (если ещё не собран) (ЗАПУСКАТЬ ИЗ КОРНЯ ПРОЕКТА) ---------
docker run -it --rm -v ${PWD}\sinks\mongodb-handler:/usr/src/mymaven -w /usr/src/mymaven maven:3.8-openjdk-11 mvn clean package

После успешной сборки необходимо переместить jar ко всем jar-ам:
move -force sinks\mongodb-handler\target\university-cdc-handler-1.0.jar sinks\jars\


--------- 1. Пересобрать и запустить всё с нуля ---------
docker-compose down -v
docker-compose up -d

Дождаться, когда контейнер data-generator завершит работу:

docker-compose logs data-generator


--------- 2. Проверить, что Kafka Connect зарегистрировал коннектор ---------
curl.exe http://localhost:8083/connectors/postgres-connector/status

Первый запуск коннектора выполняет начальный снапшот; дождаться состояния RUNNING


--------- 3. Проверить топики dbserver.public.* с сообщениями Kafka через Kafka UI или через консоль ---------
http://localhost:8084
docker exec kafka kafka-topics --list --bootstrap-server kafka:9092
