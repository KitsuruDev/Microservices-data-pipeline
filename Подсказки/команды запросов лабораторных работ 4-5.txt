--------- 0 - 1. Собрать CdcHandler для mongodb в файл .jar (если ещё не собран) (ЗАПУСКАТЬ ИЗ КОРНЯ ПРОЕКТА) ---------
docker run -it --rm -v ${PWD}\sinks\mongodb-handler:/usr/src/mymaven -w /usr/src/mymaven maven:3.8-openjdk-11 mvn clean package

После успешной сборки необходимо переместить jar ко всем jar-ам:
move -force sinks\mongodb-handler\target\university-cdc-handler-1.0-jar-with-dependencies.jar sinks\jars\






--------- 0 - 2. Собрать LectureMaterialCdcHandler для elasticsearch в файл .jar (если ещё не собран) ---------
docker run -it --rm -v ${PWD}\sinks\elasticsearch-handler:/usr/src/mymaven -w /usr/src/mymaven maven:3.8-openjdk-11 mvn clean package

move -force sinks\elasticsearch-handler\target\elasticsearch-cdc-handler-1.0-jar-with-dependencies.jar sinks\jars\






--------- 1. Пересобрать и запустить всё с нуля ---------
docker-compose down -v; Remove-Item -Recurse -Force -ErrorAction SilentlyContinue @('.\mongodb', '.\elasticsearch', '.\redis', '.\neo4j')
docker-compose up -d

docker-compose logs data-generator
